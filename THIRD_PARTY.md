## Bundled data

- `internal/library/data/ps2_cd_titles.json` — project-generated
  known-titles list (spec §2.3 #4); ships unpopulated; user-extendable
  via `ps2_cd_titles.user.json` in the config dir.
- `web/dist` — Svelte SPA compiled from `web/` sources in this
  repository (build-time devDependencies only, resolved above when
  installed; no third-party runtime JS beyond the compiled bundle).
